 # Spatiotemporal Analysis of Insecurity in Nigeria

A CPE Club data pipeline that collects, cleans, analyzes, and visualizes Nigerian conflict data from ACLED to answer three research questions about insecurity patterns across the country.

---

## What This Project Does

It answers three operational questions:

1. **Regional** — Which states and geopolitical zones have the highest number of violent incidents?
2. **Temporal** — Are violent events increasing month by month, or do they follow a seasonal pattern?
3. **Severity** — Which types of conflict produce the most fatalities per incident?

---

## System Architecture

```
data/raw_nigeria_conflict.csv
        |
        | (downloaded from acleddata.com or generated by mock mode)
        v
+------------------+
|  fetch_data.py   |  Step 3 — loads the CSV (mock or real) and confirms it is ready
+--------+---------+
         |
         v
+------------------+
|  clean_data.py   |  Step 4 — drops bad rows, fixes types, standardizes state names,
|                  |           adds geopolitical zone and month_year columns
+--------+---------+
         |
         v
  data/clean_conflict_data.csv
         |
         v
+------------------+
|   analyze.py     |  Step 5 — answers the 3 research questions, saves results as CSVs
+--------+---------+
         |
         v
  outputs/regional_by_state.csv
  outputs/regional_by_zone.csv
  outputs/temporal_trends.csv
  outputs/severity_ratios.csv
         |
         v
+------------------+
|  visualize.py    |  Step 6 — reads the CSVs and saves 4 PNG charts
+------------------+
         |
         v
  outputs/charts/top_states_incidents.png
  outputs/charts/zones_comparison.png
  outputs/charts/monthly_trend.png
  outputs/charts/severity_ratio.png
```

## Setup

**1. Make sure Python 3.13 is installed**
```
python --version
```

**2. Install the required packages**
```
pip install pandas numpy matplotlib seaborn requests
```

**3. Get the data**

Go to [acleddata.com/conflict-data/data-export-tool](https://acleddata.com/conflict-data/data-export-tool/), filter by:
- Date: 2023-01-01 to 2024-12-31
- Country: Nigeria

Download the CSV, rename it `raw_nigeria_conflict.csv`, and place it in the `data/` folder.

---

## How to Run

**Run the full pipeline:**
```
python main.py
```

**Or run each step separately:**
```
python -m src.fetch_data
python -m src.clean_data
python -m src.analyze
python -m src.visualize
```

**To use mock data instead of the real CSV**, open `src/fetch_data.py` and set:
```python
USE_MOCK = True
```
